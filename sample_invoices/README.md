# Sample Invoices Directory

This directory stores test PDF invoice files (both digital-native PDFs and scanned image PDFs) used to validate the ingestion pipeline, OCR extraction, LLM structuring, and Qdrant semantic search capabilities.

## Structure
- `/sample_invoices/digital/`: Pure text-based generated PDF invoices.
- `/sample_invoices/scanned/`: Image/scanned PDF invoices requiring Tesseract OCR.
